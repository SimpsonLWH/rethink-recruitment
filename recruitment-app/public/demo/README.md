# Synthetic project illustrations

These SVGs are generated locally for the Rivet prototype. They are abstract UI sketches, not screenshots of real products, and they are visibly labelled SYNTHETIC DEMO. No external media, logos, photos or real people are used.

They are referenced from fictional seed facts:

- invoice-matching.svg — Noor Salmi's fictional invoice-matching project
- shift-planner.svg — Daniel Achebe's fictional volunteer shift planner
- returns-flow.svg — Aino Vikström's fictional returns-flow rebuild

The review card renders an image only when a fact genuinely carries a local image path. Non-portfolio profiles render structured responsibility/qualification/availability/result modules instead and never receive placeholder imagery.
